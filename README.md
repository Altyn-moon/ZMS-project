# 🛠 ZMS Project

Веб-приложение для автоматизации задач и отслеживания рабочего процесса сотрудников производственного отдела компании **ТОО ЖигерМунайСервис (ZMS)**.

🚀 Проект был разработан в рамках студенческого конкурса по цифровизации процессов.  
🥉 Наша команда заняла **3-е место** и получила **приз 300 000₸**.

---

## 📌 Основные функции

- 👤 Авторизация пользователей
- ⏱ Таймер задач и отображение статуса в реальном времени
- 📋 Панель управления задачами
- 🔍 Просмотр активных заданий для каждого сотрудника
- 🎨 Простой и понятный интерфейс

---

## 🛠 Используемые технологии

- **Бэкенд:** Python, FastAPI  
- **Фронтенд:** HTML, CSS, JavaScript  
- **База данных:** MySQL  
- **Инструменты:** Git, GitHub, MySQL Workbench, VS Code

---

## 🚀 Как запустить локально

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Altyn-moon/ZMS-project.git
cd ZMS-project

# 2. Создать и активировать виртуальное окружение (по желанию)
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate

# 3. Установить зависимости
pip install fastapi uvicorn mysql-connector-python

# 4. Запустить сервер
uvicorn main:app --reload
